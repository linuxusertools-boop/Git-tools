Nexu GitHub Deployer Pro - Source Code

Deployment Engine v2.0 - Full Fix & Stable

1. Deskripsi Sistem

Dokumen ini berisi kode sumber lengkap untuk aplikasi web Nexu GitHub Deployer Pro. Aplikasi ini dirancang untuk melakukan proses "Wipe & Rebuild" pada repositori GitHub menggunakan file ZIP secara efisien dan aman.

2. Fitur Utama (Full Fix)

  • Auto Branch Detection: Mendeteksi branch utama (main/master) secara otomatis dari API GitHub.
  • Smart Path Stripping: Jika semua file di dalam ZIP berada di dalam folder (misal tes/file.js), sistem akan otomatis mengeluarkan file tersebut ke root repository.
  • Binary Stable: Menggunakan ArrayBuffer dan FileReader untuk menangani file biner (gambar/PDF) tanpa resiko corrupted zip.
  • Error Handling: Validasi ketat pada setiap tahapan API GitHub (Blobs, Trees, Commits, Refs).
